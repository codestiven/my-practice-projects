# Proyecto: Generador de Contraseñas Aleatorias

## Descripción
Este proyecto genera contraseñas aleatorias que cumplen con ciertas reglas de seguridad. La contraseña debe tener entre 8 y 12 caracteres, incluir al menos una letra mayúscula, una minúscula, un número y un símbolo especial.

## Reglas para la contraseña:
1. La longitud de la contraseña debe ser de entre 8 y 12 caracteres.
2. Debe contener al menos:
   - Una letra mayúscula.
   - Una letra minúscula.
   - Un número.
   - Un símbolo especial (como `!`, `@`, `#`, `$`, `%`, etc.).
3. La contraseña debe generarse de manera aleatoria y no puede repetirse.

## Instrucciones:
El programa generará y mostrará contraseñas que cumplan con las reglas anteriores. Además, permite al usuario especificar cuántas contraseñas desea generar.

## Ejemplo de ejecución:

```plaintext
Ingrese la cantidad de contraseñas a generar: 3
Contraseña 1: G8@hR1n!
Contraseña 2: qL4#zP1a
Contraseña 3: X$7rTm3
